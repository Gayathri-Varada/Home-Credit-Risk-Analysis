## Project Overview
This project explores customer financial data to analyze credit risk and build machine learning classification models. It focuses on exploratory data analysis, preprocessing pipelines, and model evaluation on a large, imbalanced dataset.

## Technologies Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn, Imbalanced-learn

## Workflow
- Data inspection and exploratory data analysis (EDA)
- Data cleaning and preprocessing
- Machine learning pipeline implementation
- Model training and evaluation
- Precision, recall, F1-score, and ROC-AUC analysis

## Models Used
- Logistic Regression
- Support Vector Machine (SVM)
## Key Learnings
- Working with a large dataset containing numerous features
- Implementing preprocessing and machine learning pipelines
- Understanding class imbalance and evaluation metrics
- Analyzing the trade-off between precision and recall
